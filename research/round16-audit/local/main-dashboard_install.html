How It Works

What happens after you install the pixel.

Automatic Email Detection

The pixel monitors all email input fields (type=email, name/id containing 'email') and form submissions. No code changes needed.

Cross-Site Identification

Once a visitor enters their email on any site in the network, they're identified everywhere — automatically, without entering their email again.

SPA Support

Full single-page app support. The pixel tracks navigation via History API and popstate events — works with React, Vue, Angular, etc.

Async & Lightweight

The pixel loads asynchronously and won't block page rendering. Typical load time is under 100ms.
