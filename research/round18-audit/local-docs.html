Documentation

Get started with Pixelco in under 5 minutes.

1. Create Your Account

Sign up for a free Pixelco account and add your website domain in the dashboard.

2. Install the Pixel

Copy the pixel code snippet and paste it into the <head> section of your website, just before the closing </head> tag.

3. Verify Installation

Visit your website and check the Pixelco dashboard — you should see a green 'Active' status within a few minutes.

4. Start Identifying

That's it! Pixelco will begin identifying anonymous visitors and populating your dashboard with contact data in real time.

Example Pixel Code

⚠️

This is a sample snippet for illustration only. Your real, unique pixel code will be generated automatically when you complete onboarding in your Pixelco dashboard.

SAMPLE
<!-- Pixelco Tracking Pixel -->
<script>
  (function(p,i,x,e,l){
    p._pxid=p._pxid||[];
    var s=i.createElement('script');
    s.async=true;
    s.src='https://cdn.pixelco.com/pixel.js';
    s.setAttribute('data-site-id',e);
    var f=i.getElementsByTagName('script')[0];
    f.parentNode.insertBefore(s,f);
  })(window,document,'pxid','YOUR_SITE_ID');
</script>

Platform-Specific Instructions

WordPress

Go to Appearance → Theme Editor → header.php. Paste the pixel code before </head>. Or use a plugin like 'Insert Headers & Footers'.

Shopify

Go to Online Store → Themes → Edit Code → theme.liquid. Paste the pixel code before </head>.

Webflow

Go to Project Settings → Custom Code → Head Code. Paste the pixel code and publish.

Wix

Go to Settings → Custom Code → Add Custom Code. Paste the pixel code, set it to load on all pages in the Head.

Next.js / React

Add the script tag to your _document.tsx (Next.js) or index.html (React/Vite) inside the <head> tag.

Custom HTML

Paste the pixel code directly into the <head> section of every page, or in your shared layout/template file.

Common Questions

Does the pixel slow down my website?

No. The Pixelco script is loaded asynchronously and is under 5KB — it has zero impact on page load speed.

Is the pixel GDPR compliant?

Pixelco is 100% cookieless and does not use cookies or local storage. However, you should consult your legal team about disclosure requirements in your jurisdiction.

How quickly will I see results?

You'll start seeing identified visitors within minutes of installation. Results improve over the first 24-48 hours as more traffic flows through.
